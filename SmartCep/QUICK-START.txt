⚡ INÍCIO RÁPIDO (3 PASSOS)

1️⃣  CRIAR BANCO MySQL

   Via Docker (recomendado):
   
   docker run --name smartcep-mysql \
     -e MYSQL_ROOT_PASSWORD=root \
     -e MYSQL_DATABASE=smartcep \
     -p 3306:3306 \
     -d mysql:8.0

   Via MySQL local:
   
   mysql -u root -p -e "CREATE DATABASE smartcep CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

──────────────────────────────────────────────────────────────

2️⃣  APLICAR MIGRATIONS

   cd /home/usuario/Documentos/Apreendizado\ DOT\ NET/SmartCEP-API/SmartCep
   
   dotnet ef database update \
     --project SmartCep.Infrastructure \
     --startup-project SmartCep.Api

──────────────────────────────────────────────────────────────

3️⃣  POPULAR COM DADOS DE TESTE

   Docker:
   docker exec -i smartcep-mysql \
     mysql -u root -proot smartcep < seed-database.sql

   Local:
   mysql -u root -p smartcep < seed-database.sql
